## 스타일

- 오로라 + 글래스모피즘: 큰 색 덩어리 5개가 천천히 떠다니는 배경 위에, 흐림(backdrop blur)·7% 흰색·1px 하이라이트를 준 유리 카드. 지금 소개하는 도구의 색으로 배경 한쪽이 바뀝니다. [mg-styles-15](https://github.com/Vincentwei1021/mg-styles-15)의 Aurora & Glassmorphism 기법을 세로 숏폼에 맞게 가져왔습니다.
- 모든 프레임은 시간 t의 함수(`window.renderAt(t)`)이고, 헤드리스 Chromium으로 한 장씩 캡처합니다(mg-styles-15 하네스와 같은 방식).
- 로고는 각 회사의 실제 로고 대신 이니셜 타일(GPT, P, C, G, CN)로 표시했습니다.

## 파일

- `narration.json` — 대본. `say`는 TTS 문장(발음대로), `sub`는 자막(`|`로 카드 분리), `marks`는 화면 연출을 맞출 단어.
- `tts.py` — 문장별 음성을 `out/vo/`에 캐시하고, 실제 길이로 `timeline.json`(장면 길이·자막·연출 시점)과 `out/vo.wav`를 만듭니다.
- `index.html` — 화면 전체. `timeline.json`을 읽어 목소리에 맞춰 움직입니다.
- `audio.py` — 배경음악·효과음을 코드로 합성하고 내레이션을 얹습니다(목소리가 나올 때 음악이 줄어듦).
- `render.mjs` — 프레임 캡처 → MP4.
- `assets/sites/*.jpg` — 2026-10-22에 Firecrawl로 찍은 각 공식 사이트 화면.

## 내레이션

- 목소리: Fish Audio `2,30대 남성 (정보성 유튜버)` (`8f554770038046a382259c8871cc325d`), 모델 `s2.1-pro`.
- 이번 음성은 Fish Audio API 크레딧 대신 플랫폼(무료 플랜) 크레딧으로 생성해 `out/vo/` 캐시에 넣었습니다. API 크레딧이 있으면 `FISH_API_KEY=... ./make.sh`로 다시 생성됩니다.

```bash
FISH_API_KEY=... ./make.sh      # 음성 → 타임라인 → 큐 → 사운드 → 렌더
DRY=1 ./make.sh                 # 음성 없이 예상 길이로 레이아웃만 미리 보기
```
